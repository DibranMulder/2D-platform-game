# Selected World Map Direction

## Enchanted Chronicle v1

`enchanted-chronicle-v1.png` is the approved visual direction for the world-map hierarchy.

- Selected: 2026-08-22
- Status: approved style reference; map geography and labels remain exploratory
- Style foundation: the approved cinematic storybook-anime lineage reference
- Presentation: an illustrated magical chronicle opened across two pages
- Interaction model: players select a large territory on the world map, then enter a region map containing individual connected maps
- Discovery: hidden maps are omitted until their entrance or route has been discovered
- Navigation: every playable map exposes a portal path onward and a return route
- Scale target: hundreds of maps; strongholds contain 5-10 maps and dungeons support paths at least 10 maps deep

Future world, region, stronghold, dungeon, and hidden-map concepts should preserve the image's warm illuminated-paper palette, crystalline landmark lighting, readable landmass silhouettes, and storybook-anime fantasy rendering. The decorative frame should support navigation rather than compete with clickable regions.

The generated lettering and geography in this image are not final game content. Production labels and interaction overlays should be implemented separately in Godot for accessibility and localization.
