# Lineage silhouette exploration — v1

Status: rejected as a coherent set; retained for exploration history only  
Generated: 2026-08-22  
Tool: Codex built-in image generation

These eight sheets implement the first concept-art task from
`docs/design/0008-playable-lineage-art-direction.md`: ten black silhouette
explorations per playable Lineage, including varied builds and non-combat roles.

The set must not be used as the style reference or advanced directly into
production. The individual generations drifted between incompatible rendering
and shape languages, and many figures carried occupational props instead of
gameplay equipment. A future pass must follow the selected cinematic
storybook-anime reference and the shared carried-equipment rule in the art brief.

## Review method

1. View every sheet at the same scale.
2. Reduce each character to roughly 72–80 pixels tall.
3. Reject silhouettes whose Lineage or role cannot be read at that size.
4. Mark promising figures by sheet name and position: top row 1–5, then bottom
   row 6–10.
5. Compare the chosen figures together before requesting detailed character
   sheets or production sprites.

## Prompt record

Shared prompt: create exactly ten original, full-body, right-facing character
silhouettes for a storybook high-fantasy side-scrolling MMORPG. Arrange them in
two rows of five on white, with solid black figures, a shared baseline, clear
negative space, varied ages/genders/builds, and at least six civilian or
non-combat professions. Communicate identity through outer contour, anatomy,
clothing shape, tools, and carried objects. Avoid internal rendering, text,
watermarks, scenery, and recognizable franchise designs.

Lineage-specific prompt material came directly from the anatomy, materials,
shape-language, profession, stereotype-avoidance, and open-decision sections of
the art-direction document. A focused edit pass converted tonal/dark-background
results into black-on-white comparison sheets without intentionally redesigning
their poses or contours.

## Known limitations

- These are ideation sheets, not exact orthographic model sheets.
- Some sheets retain small interior negative-space accents from the generation.
- Apparent costume details are suggestions only and are not canon.
- Aeralith deliberately mixes winged, gliding, and non-winged hypotheses.
- Sunscour and Rimeborn anatomy remains provisional as required by the brief.
