# Playable Lineage Silhouettes — v2

This review set regenerates all eight playable Lineages using one shared silhouette-sheet system. It supersedes `v1` for review but does not yet canonize individual bodies, costumes, symbols, or equipment designs.

## Shared visual grammar

- Approved style foundation: `art-source/style-references/cinematic-storybook-anime-v1.png`
- Landscape 1536x1024 sheet with two rows of five right-facing characters
- Warm ivory background, pale row baselines, black filled silhouettes, and restrained ivory contour separations
- Consistent cinematic storybook-anime proportions, spacing, equipment scale, and presentation
- Lineage identity comes from anatomy, posture, garments, and outer contour—not a different rendering technique
- Exactly ten visibly armed characters per Lineage; profession and travel gear remain secondary
- No dual wielding; Shields pair only with One-Handed Weapons; Two-Handed Weapons occupy both hands

## Equipment slots
