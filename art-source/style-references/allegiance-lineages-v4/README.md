# Allegiance Lineage Style References — v4

This is the current paired review set. The Light plate is carried forward unchanged from v3. The Dark plate revises the Deep Goblin, Sunscour, and Rimeborn using the user-provided visual references while retaining the approved child-friendly storybook rendering.

## Dark Lineage revisions

- **Crag Troll:** unchanged from v3.
- **Deep Goblin:** strange, memorable facial anatomy with very large ears, uneven yellow eyes, raised goggles, a long angular nose, pronounced cheeks, a protruding upper lip, and an alert skeptical expression. Broad facial cues came from `../../concepts/lineage-silhouettes/ref/goblin.png`.
- **Sunscour:** layered weathered dark-red desert robes, indigo under-layer, practical lamellar shoulder cape, wrapped forearms, head wrap, and lower-face veil. Broad costume cues came from `../../concepts/lineage-silhouettes/ref/haradrim.png`.
- **Rimeborn:** distinctly nonhuman cold-adapted anatomy with slate skin, large reflective ice-blue eyes, a broad nose, pale wiry facial hair, and an oversized frost-white fur hood. Broad anatomical cues came from `../../concepts/lineage-silhouettes/ref/frostling.png`.

The references inform visual traits only. Exact characters, costumes, armor patterns, symbols, props, and poses are not copied.
