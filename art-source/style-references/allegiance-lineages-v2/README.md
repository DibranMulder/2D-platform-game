# Allegiance Lineage Style References — v2

This pair replaces `allegiance-lineages-v1` as the current review direction. The v1 plates drifted toward tall, elaborate JRPG/anime character art and did not reproduce the child-friendly visual language of `cinematic-storybook-anime-v1.png` closely enough.

## Corrected shared prompt direction

- Whimsical 2D side-scrolling children's fantasy with only a light anime influence
- Compact characters around 3.5–4 heads tall, with large heads, simple rounded faces, and readable hands and feet
- Youthful, friendly, toy-like clarity without baby or super-deformed proportions
- Simplified chunky clothing, broad color blocks, minimal ornament, and practical gameplay equipment
- Clean dark contours, soft cel-painted shading, and a smooth hand-painted 2D game-art finish
- Large fairy-tale environments with platform-like terrain and layered atmospheric depth
- Characters presented as small adventurers inside a wondrous world—not tall heroic models in an anime party poster
