# Alegreya launcher fonts

The Chronicle launcher uses the following fonts from the official Google Fonts
repository:

- `AlegreyaSC-Medium.ttf` for display and section headings.
- `AlegreyaSans-Regular.ttf` for body copy and form fields.
- `AlegreyaSans-Medium.ttf` for buttons and compact UI labels.

Both families are distributed under the SIL Open Font License 1.1. The complete
license text for each family is included beside the font files.

Sources:

- <https://github.com/google/fonts/tree/main/ofl/alegreyasc>
- <https://github.com/google/fonts/tree/main/ofl/alegreyasans>
